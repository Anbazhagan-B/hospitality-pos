Design and implement a Payment Gateway Service with the following requirements:

- **RESTful API Development**: Create secure RESTful endpoints to process payments using credit cards, loyalty cards, gift cards, and casino tender.
- **Security**: Ensure all payment data is handled securely, following PCI DSS guidelines for encryption and data protection.
- **Check Service Integration**: Implement API calls to integrate with the Check Service, enabling payment processing for transactions linked to checks.
- **Documentation**: Provide API documentation detailing endpoints, request/response formats, authentication, and error handling. Reference [OWASP REST Security](https://owasp.org/www-project-api-security/) for best practices.
- **Testing**: Include unit and integration tests for all payment methods and Check Service interactions.
- **Constraints**: Use industry-standard libraries for payment processing and secure communication. Ensure the service is stateless and scalable.
