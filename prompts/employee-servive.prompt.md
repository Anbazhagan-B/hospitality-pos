Design and implement an Employee Service with the following specifications:

- **Authentication and Authorization**: Develop RESTful APIs for employee login, logout, and authentication using JWT tokens. Ensure all incoming requests validate JWT tokens for both authentication and authorization.
- **Employee Management**: Implement CRUD operations for employee data, including management of roles and permissions.
- **Security Integration**: Integrate the service with an ingress controller to handle incoming requests and enforce security policies.
- **Constraints**: Use industry-standard libraries for JWT handling and follow best practices for RESTful API design. Ensure all endpoints are documented and include error handling for authentication failures.
- **References**: Refer to [JWT documentation](https://jwt.io/introduction/) and [RESTful API guidelines](https://restfulapi.net/) for implementation standards.
