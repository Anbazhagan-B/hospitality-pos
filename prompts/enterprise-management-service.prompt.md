Enterprise Management Service:- Design and implement an Enterprise Management Service with the following specifications:

- **Organization Management**: Create RESTful APIs to handle CRUD operations for managing organizations, including creating, updating, retrieving, and deleting organization tender, items, profit center, data. Ensure endpoints follow standard REST conventions and validate input.
- **Employee Association**: Implement functionality to associate employees with organizations. Provide endpoints to add, remove, and list employees within a specific organization.
- **Security**: Ensure all endpoints are secured, implementing authentication and authorization mechanisms to restrict access based on user roles and permissions.
- **Documentation**: Document all API endpoints, including request/response schemas, authentication requirements,
  and error codes, using OpenAPI/Swagger.
- **Constraints**: The service must be implemented in Java using Spring Boot. Follow best practices for code structure, exception handling, and logging.

Create docker and ingress controller configurations for deploying the service in a containerized environment.
