Design and implement a Cook Service that generates a JSON configuration for a terminal application. The service must:

- Define menu items, including names, descriptions, and unique identifiers.
- Organize menu items into categories (e.g., appetizers, main courses, desserts).
- Specify available modifiers for each menu item (e.g., size, add-ons, dietary options).
- Include detailed pricing information for each item and modifier.
- Ensure the generated JSON structure is well-formed and adheres to standard JSON conventions.
- Provide sample JSON output and reference the [JSON documentation](https://www.json.org/json-en.html) for format guidelines.

The service should be modular, allowing easy updates to menu items, categories, modifiers, and pricing.
